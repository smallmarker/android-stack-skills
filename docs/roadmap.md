# Roadmap

V1 focuses on deterministic Android Kotlin/Compose integration, three tested Recipes and two project presets. Remaining validation gaps are listed in delivery.md.

Future candidates, outside this implementation: Room, DataStore, Navigation, permissions, events, multiple Gradle modules, Ktor, Glide, XML/View image support, Recipe upgrade migrations and an Android Recipe Distiller. Add them only with explicit compatibility boundaries, provenance, conflict protection and real build tests. No cloud platform, Recipe marketplace or general Skill Creator is planned for V1.
